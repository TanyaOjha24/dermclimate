# Research Papers

The research papers used by DermClimate are not included in this repository due to copyright restrictions.

To use the ingestion pipeline:

1. Download the required papers.
2. Place the PDFs in this directory.
3. (Upcoming) Run the metadata generator.
4. Run:

```bash
python -m app.ingest_paper
```

## Status

- Current ingestion uses temporary paper metadata.
- A metadata generation pipeline will replace the temporary metadata in a future update.
